How these are measured

The site holds one open connection to Wikimedia EventStreams, the public feed carrying every change saved on Wikipedia, and counts events as they arrive. Days are UTC calendar days, counted end to end. An edit is a saved change to an article — the main namespace — in any language edition, and bot edits are included because they are edits. Nothing here is sampled, cached or projected from a smaller number.

A day the server did not watch from its first minute is never published: a restart would leave a partial count that reads like a real one. If a figure is missing below, that is why.

The CSV carries one row per day with all_edits, located_edits, new_articles, new_articles_by_people, geotagged_photos and the day's most-edited place. Where a day was not watched from its first minute the edit count is left empty and all_edits_complete reads false, because a short count is worse than a missing one.
