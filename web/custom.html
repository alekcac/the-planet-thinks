A CSV needs lat and lon columns (or latitude/longitude). Optional: title, category — which picks the colour — weight, url, time. GeoJSON points work as they are. A stream should send one JSON object per event with the same fields; it must allow cross-origin requests, and on this HTTPS page it has to be https or wss.
