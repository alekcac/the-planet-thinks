Or just paste the link

Notion, WordPress, Ghost, Discourse, Obsidian Publish and most wikis speak oEmbed: paste https://theplanetthinks.com/ on its own line and the editor asks this site how to display it, then puts the globe there by itself. No snippet, no HTML mode. If a tool strips iframes from pasted HTML — many hosted blogs do — this is the way in.

Questions people ask before pasting

Is it free?

Yes, and free in both senses: no account, no API key, no quota, no tracking cookies, and the code is open source under the MIT licence. The Earth imagery is NASA's public-domain Blue Marble and Black Marble.

Will it stop working one day?

There is nothing in the snippet that can expire — no key to rotate, no version to pin. It is a plain iframe pointing at a public URL, and it shows whatever that URL shows.

Will it slow my page down?

The snippet sets loading="lazy", so nothing loads until a reader scrolls near it. The globe is a lightweight WebGL scene that runs on modest laptops and streaming sticks.

Does it need credit?

A small corner badge inside the embed links back here, and the snippet adds a credit line underneath. Keeping that line is appreciated rather than required.

Can I make it full screen instead?

Yes — the same URL without the iframe is a full-screen ambient display. See running it as a screensaver on a TV or second monitor.
